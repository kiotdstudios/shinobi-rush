Transparent nine-tile masks use the existing72x36 diamond grid. The source/ directory is excluded from Godot imports and exports but retained in Git for provenance. PixelLab use: three Pro sources plus three 16-frame animation jobs. No background/shore/rock/plant art included.

Runtime: BlightwoodWater; builder filter River water. Decorative pass only, no swimming or collision changes. Normal/half previews and integration notes: docs/visuals/blightwood-water/README.md.
