# Shinobi Rush — Jutsu Build Cards

Individual illustrated **Markdown stat cards** for jutsu/build examples, following the Fireball stat breakdown. These are editable design mockups, not exported artwork or final balance data.

**Shared rules:** global Jutsu Power increases offensive jutsu damage; equipment can grant multiple flat and percentage modifiers; elemental bonuses apply to matching direct damage; status-effect bonuses such as Burn Damage apply to their matching status ticks. Jutsu mastery is independent of global Jutsu Power. Damage formula and stacking are illustrative and pending balancing.

**Roster status:** Fireball is an example, Lightning Strike / Wind Palm / Shadow Clone are GDD prototypes, and Substitution is confirmed as an L2 ability. None of these mockup numbers or named equipment bonuses is final.

## Template for future jutsu

Each new technique gets its own file in this folder: identity, effect, base stats, global bonuses, targeted equipment, computed output, mastery path, and status (confirmed/prototype/example). If a jutsu does not deal damage, show its relevant cooldown, duration, charges, or defensive properties instead.
