# Shinobi Rush — Controls

Source: `project.godot` input map on main. Xbox / PlayStation gamepad equivalents shown.

| Action | Keyboard | Controller |
|---|---|---|
| Move | W A S D | Left stick |
| Sprint | Shift | R1 / RB |
| Light attack | J | X / Square |
| Heavy attack | K | Y / Triangle |
| Dodge | Space | B / Circle |
| Jump | F | A / Cross |
| Heal | E | L1 / LB |
| Substitution (tap) | Q | LT / L2 (tap) |
| Chakra charge | C | Hold LT / L2 |
| Jutsu modifier | — | RT / R2 |
| Pause | Esc | Menu / Start |
| Item slots (up / right / down / left) | Arrow keys | D-pad (default: health gourd / chakra gourd / empty / kunai) |
| Player menu (Inventory + Jutsu tabs) | I | Touchpad (the large black button) |
| Lock on / off (nearest enemy in range) | L | R3 (click the right stick) |
| Aim | not used yet | Right stick (reserved) |

## Testing shortcuts (keyboard)

- Tab (keyboard) / Select-Back (controller): Toggle animation/combat lab
- C: visual comparison (NOTE: C is also bound to chakra charge, both fire); Z: camera zoom
- [ / ]: sprite set; , / .: animation; ; / ': direction; V: follow facing
- 1–6: visual overlays; P / O: pause / step animation

These are configured bindings, not a guarantee that every prototype action is fully implemented. Canonical live build: https://kiotdstudios.github.io/shinobi-rush/
